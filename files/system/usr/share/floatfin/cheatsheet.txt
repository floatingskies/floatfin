Floatfin quick reference
========================
The wizard's terminal: everything here is baked into the image already.


### beginner — the easy tour
There's nothing to install to get started. A couple of things you'll want:

  • Open apps ................ the GNOME overview (Super key), or type to search
  • Open the terminal ........ Super, type "terminal", or press Ctrl+Alt+T
  • First update ............. sudo bootc upgrade && systemctl reboot
                                 (your whole OS updates atomically — like a phone)
  • Install software ......... three ways, pick your favourite:
      - Flatpak/GNOME Software .. most GUI apps, sandboxed:        flatpak install flathub <app>
      - dnf native RPMs ......... system packages:                 sudo dnf install <pkg>
      - distrobox ............... any other distro's packages:      distrobox enter fedora
  • Still lost? ................ run `gnome-tour` for the interactive intro.

  Tip: `float` from any terminal re-opens this menu.


### workbench — set up shop
Terminal-first, but comfy:

  • Drop into any distro ................. distrobox enter fedora
        (Box mounts your home directory — data is shared, system is isolated)
  • Run one command from nixpkgs ......... nix run nixpkgs#htop
  • Ephemeral dev shell ................... nix develop nixpkgs#python3
  • Run local containers .................. podman run --rm -it fedora:latest bash
  • Share work over ssh ................... ssh user@hostname   (server + client ready)
  • Set up a timer/ops on another box ..... open https://<host>:9090  (Cockpit)

  File-navigation with the tools built in:
      ls / ll ......... eza (colours/icons)        cat ......... bat (syntax highlight)
      cd .............. zoxide (jump to favourites) find ......... fd
      grep ............ rg (ripgrep)                top ......... btop
      du / df ......... duf                         tree ......... eza --tree


### power — system power tools
The immutable core, driven from the terminal:

  • See what you're running ............... bootc status
  • Manual upgrade ........................ sudo bootc upgrade
  • Rebase to another image ................ sudo bootc switch <image>
  • Roll back after a bad boot ............. sudo bootc rollback  (then reboot)
  • Verify image signatures ................ cosign verify --key cosign.pub ghcr.io/floatingskies/floatfin:gts
  • Audit enabled services ................. systemctl list-unit-files --state=enabled
  • Inspect RAM footprints ................. systemd-analyze blame | head;  journalctl --disk-usage
  • Firewall .............................. sudo firewall-cmd --list-all
  • Cockpit console ........................ systemctl status cockpit   →  https://localhost:9090
  • Nix store + daemon ..................... systemctl status nix-daemon;  nix doctor

  Everything under /usr is read-only by design; use the store/layers, not hacks.
