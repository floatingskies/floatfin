the easy way to a terminal-first desktop

Floatfin.

An immutable, signed, bootable-container desktop built on Bluefin DX, Bazzite (GNOME) and Fedora Atomic. Terminal-first, but friendly: every tweak is baked in at build time — the whole GNOME app set, distrobox, Nix with flakes, a socket-activated sshd, and a wizard that walks you through it all.

why it's worth a look

Everything is baked in. Nothing breaks you into it.

  • Atomic & signed — immutable images with clean rollbacks, verified with cosign.
  • Terminal-first, wizard-guided — a curated fish + Starship prompt in Fira Code, aliases to eza/bat/btop/zoxide, and the float wizard: an easy tour, a workbench and power tools, all from one command.
  • Containers baked in — rootless Docker + podman, Cockpit on :9090, sshd socket-activated, distrobox (any distro's packages, sharing your home), and Fedora's official Nix with flakes on.
  • The whole GNOME core, native RPMs — Calendar, Clocks, Contacts, Maps, Weather, Connections, Calculator, Text Editor, seahorse… plus the GNOME Tour for first-timers. No flatpaks baked in.
  • Lean GNOME — ~1.5 GB idle RAM: idle services and bloat purged, animations off, tuned swap and BBR.
  • Gaming ready — Steam, GameMode, Gamescope, Mangohud (32-bit included), Vulkan tools.
  • One desktop, three bases — the same curated GNOME on Silverblue, Bluefin and Bazzite.

Getting Floatfin.

The live ISOs come straight from CI: the card below is filled with the most recent successful Build Live ISOs artifact. GitHub trims artifacts after a while, so if the link is gone, trigger the workflow yourself — a fresh .zip appears on the run page.

Looking for the last successful build…

Download the ISO (.zip) Browse CI runs

Then what? Four ways to use it:

  1. Download the .zip — inside you'll find a *-live-amd64.iso plus its -CHECKSUM. Verify before flashing: sha256sum -c *.iso-CHECKSUM.
  2. Write it to a USB stick — drop the ISO onto Ventoy with nothing else to do, use Rufus on Windows, or balenaEtcher on macOS/Linux. (Or the classics: sudo dd if=Floatfin.iso of=/dev/sdX bs=4M status=progress.)
  3. Boot it — the live desktop appears; pick Install to Disk (Anaconda) to install. Secure Boot works with the Universal Blue enrollment key.
  4. Or try it in a VM first — just boot the ISO in GNOME Boxes, QEMU/KVM, VirtualBox or UTM. Nothing touches your real disk.

already on linux?

Rebase, don't reinstall.

On any Fedora Atomic / Universal Blue image, switching is one command — then pick the older boot entry if anything feels off. 

sudo bootc switch ghcr.io/floatingskies/floatfin:latest --enforce-container-sigpolicy
systemctl reboot

Day-1 refreshers: float (the wizard), distrobox enter fedora, nix run nixpkgs#hello, Cockpit at https://<host>:9090.
